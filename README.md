# Multitasking

Train up to 5 skills at the same time in Melvor Idle 2. A "Simultaneous Actions" slider
(1 to 5) on the Mods page of the game's settings: with it above 1, starting a skill no
longer stops the one already running. When every place is taken, the action that has
been running longest stops. One action per skill, as always.

Time away runs every action that was going. A save made with several running loads in
the unmodded game with all of them still going, until something new is started.

It changes how the game plays, so it is tagged as a cheat: the mod manager asks before
every start with it switched on.

A umitoo mod:

    umitoo run .        try it in the test profile
    umitoo publish .    send it to the registry
